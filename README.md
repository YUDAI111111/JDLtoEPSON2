**JDL to Epson 仕訳変換エンジン**

JDL形式の仕訳データをEpson財務会計形式のCSVへ変換し、会計ソフト間の移行を自動化するためのツールです。

Google Apps Script（GAS）をベースに構築しており、実務上の課題である「ソフト間の構造的相違」をプログラムによって解決します。

**概要**

会計事務所の実務において、JDLとEpsonの勘定科目体系には、特に銀行口座の扱いにおいて構造的な差異が存在します。

本ツールは、その差異を解消するための独自の「銀行特例処理」や、文字列アルゴリズムを用いた「科目マッピング機能」を搭載しています。

**主な機能**
1. 銀行口座科目の特例処理
JDLとEpsonのデータ構造の差異を、独自の判定ロジックで自動的に吸収します。

背景: JDLは「普通預金（科目）＞ 銀行名（補助）」という親子構造ですが、Epsonは「銀行名（科目）」という独立した構造を持っています。
解決策: 補助科目名をスキャンし、特定の金融機関（八十二銀行、長野信用金庫等）を自動検知して、Epson側の正しい勘定科目コードへ強制的に振り替えます。

3. 多段階マッピングアルゴリズム
名称の揺らぎによる変換ミスを防ぐため、以下の判定ロジックを実装しています。

完全一致: 名称が一致する科目を自動紐付け。
部分一致（LCSアルゴリズム）: 最長共通部分列（LCS）アルゴリズムを用いて名称の類似度をスコアリングし、候補を提示。
不一致: 紐付けが不明な項目を赤色でハイライトし、手動選択を促します。

3. 学習型マッピングストア
確定したマッピング情報は、別のシート（データベース）に永続化されます。
次回以降の変換時には、この履歴を優先的に参照するため、使えば使うほど自動化率が向上します。
情報が不足している場合でも、マスターデータから名称やコードを逆引きして補完する「連鎖補完ロジック」を搭載しています。

4. ユーザーインターフェース（UI/UX）
動的バリデーション: スプレッドシート上で親科目を選択すると、対応する補助科目のみが選択肢に表示される動的プルダウン機能を実装。
リアルタイム進捗サイドバー: 大量データの処理状況（進捗率、エラー件数、推定残り時間）を、HTMLサイドバーを通じてリアルタイムに表示します。

5. 技術的な仕様
入出力: JDL仕訳データ（CSV/スプレッドシート）から、Epson公式ヘッダ（44項目）準拠のCSVを生成。
文字コード: 日本の会計ソフトのインポート仕様に合わせ、Shift_JIS および CRLF（改行コード）で出力。
堅牢性: 税区分の不整合やマッピング未了がある場合、不完全なデータ出力を防ぐためのガードロジックを搭載。

**使用技術**
言語: Google Apps Script (JavaScript)

フロントエンド: HTML / CSS (進捗表示用サイドバー)

アルゴリズム: LCS (Longest Common Subsequence)

マスターデータについて
変換の基準となるEpsonの科目リストは、公式の基準データを元に実務上の視認性を高める加工を施した上でインポートして使用しています。
